Lesson 9 ‒ まとめ

There is / are の早見表

単数（1つ）複数（2つ以上）
肯定文There is a 〜.There are 〜s.
否定文There isn't any 〜.There aren't any 〜s.
疑問文Is there a 〜? — Yes, there is. / No, there isn't.Are there any 〜s? — Yes, there are. / No, there aren't.
⚠ my 〜・the 〜 など特定の名詞には there 構文は使えない（例：My bag is 〜）。否定文・疑問文では some → any。

Lesson 9 ‒ Practice A

（ ）から選ぶ（am / is / are）

1There ( am / is / are ) a dictionary under the desk.
→ isa dictionary（単数）／机の下に辞書が1冊ある。
2( Am / Is / Are ) there any pictures on the wall?
→ Arepictures（複数）／壁に絵がありますか。
3There ( am / is / are ) 40 students in our class.
→ are40 students（複数）／私たちのクラスには40人の生徒がいる。
4( Am / Is / Are ) there a microwave oven in your house?
→ Isa microwave oven（単数）／家に電子レンジはありますか。
5There ( am / is / are ) some cars in front of the station.
→ aresome cars（複数）／駅前に車が何台かある。

Lesson 9 ‒ Practice B

対話を完成させる

1Is ( there ) any juice in the refrigerator? —No, ( there ) ( isn't ).
there / there / isn't　冷蔵庫にジュースはありますか。— いいえ、ありません。
2( Are ) ( there ) any flowers in the garden? —( Yes ), ( there ) ( are ).
Are / there / Yes / there / are　庭には花がありますか。— はい、あります。
3( Is ) ( there ) an air conditioner in your room? —( Yes ), ( there ) ( is ).
Is / there / Yes / there / is　部屋にエアコンはありますか。— はい、あります。

Lesson 10 ‒ Practice A

進行形（be動詞＋-ing）を選ぶ

1They ( is / are )( play / playing ) catch now.
→ are playingThey → are／彼らは今キャッチボールをしている。
2I ( was / were )( haveing / having ) dinner then.
→ was havingI の過去 → was。have → having／私はそのとき夕食を食べていた。
3My parents ( was / were )( watch / watching ) TV when I came home.
→ were watchingparents（複数）→ were／帰宅したとき両親はテレビを見ていた。
4Emi ( is / was )( writeing / writing ) a letter now.
→ is writingnow → is。write → writing／エミは今手紙を書いている。
5It ( is / was )( raining / rainning ) hard at that time.
→ was rainingat that time → was。rain → raining／そのとき激しく雨が降っていた。

Lesson 10 ‒ Practice B

「〜しているところですか」とたずねて答える

1( Is ) she ( reading ) a comic book now? —Yes, ( she ) ( is ).
Is / reading / she / is　マンガを読んでいますか。— はい。
2( Are ) they ( playing ) volleyball now? —No, ( they ) ( aren't ).
Are / playing / they / aren't　バレーをしていますか。— いいえ。
3( Was ) she ( watching ) a movie then? —No, ( she ) ( wasn't ).
Was / watching / she / wasn't　（絵はニュース）映画を見ていましたか。— いいえ。
4( Were ) they ( drinking ) wine then? —Yes, ( they ) ( were ).
Were / drinking / they / were　ワインを飲んでいましたか。— はい。

Lesson 10 ‒ チャレンジ＆文法知っ得

並べかえ／進行形にできない動詞

1私の父は電話中です。( my father / talking / is ) on the phone.
→ My father is talking on the phone.
2あなたはトムを待っているのですか。( you / are / Tom / waiting for )?
→ Are you waiting for Tom?
3翔太は部屋で宿題をしていましたか。( doing / Shota / his homework / was ) in his room?
→ Was Shota doing his homework in his room?
○進行形にできない動詞（○をつける）
→ ① know・③ love・⑤ hope・⑥ want・⑧ hear・⑨ see状態を表す動詞。sing/read/listen/watch は進行形OK

まとめ

今日のポイント

① There is / are … 後ろの名詞が単数なら is、複数なら are。否定・疑問は some → any。my・the など特定の名詞には使わない。
② 進行形 ＝ be動詞 ＋ -ing。now → 現在（am/is/are）、then・at that time → 過去（was/were）。
③ -ing の作り方に注意（write→writing、run→running、lie→lying）。know・love・want など状態の動詞は進行形にしない。

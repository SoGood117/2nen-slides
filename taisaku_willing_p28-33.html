p.28 Get Ready

How ＋ 〇〇 で「どれくらい？」をたずねる

「何を」たずねたいかで、How の後ろが変わる！

表現たずねること答え方の例
How many ＋ 複数名詞数（いくつ・何人）Two.
How much値段・量15,000 yen.
How long期間・時間の長さAbout three hours.
How old年齢・古さHe is ten.
How often頻度（何回くらい）Once a week.

p.28 Practice B

下線部に入る語句は？

How many / How much / How long / How old / How often　※答えの文がヒント！

(1)How long does it take from here to Osaka? — About three hours.
「3時間くらい」＝所要時間 → How long
(2)How old is Nobita? — He is ten.
「10歳」＝年齢 → How old
(3)How much was your bike? — 15,000 yen.
「15,000円」＝値段 → How much
(4)How many sisters do you have? — Two.
sisters（複数形）の数 → How many
(5)How often do you clean your room? — Once a week.
「週に1回」＝頻度 → How often

p.30 復習問題②

まず確認！ be動詞 と 一般動詞

be動詞（am / is / are / was / were）
「〜です」「〜にいる」
否定：wasn't / weren't
疑問：Was / Were ＋ 主語 …？
一般動詞（play, watch, go …）
「〜する」
否定：didn't ＋ 原形
疑問：Did ＋ 主語 ＋ 原形 …？
⚠ 1文に be動詞 と do/does/did は同時に使わない！
⚠ 主語が3人称単数・現在なら動詞に -s（例：Who uses …?）

p.30 復習問題② ①

適切な語句を選ぼう

(1)I ( am / was / were ) a junior high school student at that time.
→ wasat that time（そのとき）＝過去。主語 I の過去は was。
(2)Where ( is / do / does ) your mother now?
→ is「今どこにいる？」動詞がない文なので be動詞。now ＝現在、your mother は単数 → is。
(3)Betty ( wasn't / doesn't / didn't ) practice the piano the day before yesterday.
→ didn't一般動詞 practice の否定＋おととい（過去）→ didn't ＋原形。
(4)( Do / Did / Are ) you watch the TV drama last night?
→ Did一般動詞 watch ＋ last night（過去）→ Did。
(5)Who ( use / uses / is ) this bike?
→ uses疑問詞 Who が主語 → 3人称単数扱い → uses。

p.30 復習問題② ③

並べかえよう

(1)ぼくたちは昨日の午後、カラオケに行きました。
( karaoke / we / yesterday afternoon / went to ).
→ We went to karaoke yesterday afternoon.主語 → 動詞 → 場所 → 時（時を表す語は文末）
(2)あなたはそのとき台所にいましたか。
( you / then / in the kitchen / were )?
→ Were you in the kitchen then?be動詞の疑問文：Were ＋ 主語 … ／「場所 → 時」の順
(3)あなたの父は毎週日曜日に、車を洗いますか。
( your father / wash / does / the car ) every Sunday?
→ Does your father wash the car every Sunday?3人称単数・現在 → Does ＋ 主語 ＋ 原形（wash）
(4)あなたは本を何冊持っていますか。
( you / many / do / how / books ) have?
→ How many books do you have?How many ＋ 名詞 をカタマリで文頭へ！

p.32 Try 1

形容詞はどこに入る？

形容詞＝名詞を説明することば（long, good, red, hot …）

パターン①　名詞の前
a / the / my / this ＋ 形容詞 ＋ 名詞
例）This is a long story.　これは長い物語です。
パターン②　be動詞の後ろ（主語を説明）
主語 ＋ be動詞 ＋ 形容詞
例）It is hot.　暑い。　／　She is busy.

p.32 Try 1

( )内の形容詞を入れよう

(1)She is my friend. (good)彼女は私の親友です。
→ She is my good friend.my と friend の間（パターン①）
(2)We have the pen. (same)私たちは同じペンを持っています。
→ We have the same pen.same はふつう the same ＋ 名詞 の形で使う
(3)I like this rose. (red)私はこの赤いバラが好きです。
→ I like this red rose.this と rose の間（パターン①）
(4)It is in summer. (hot)夏は暑い。
→ It is hot in summer.be動詞の後ろ（パターン②）。寒暖の It。
(5)Did you have snow last year? (much)昨年は雪がたくさんふりましたか。
→ Did you have much snow last year?snow は数えられない名詞 → much ＋ 名詞

p.33 Try 2

副詞はどこに入る？

副詞＝動詞・形容詞・他の副詞を説明することば

種類位置例
様子（well, fast …）動詞（＋目的語）の後ろspeaks English well
頻度（always, usually …）be動詞の後ろ
／一般動詞の前		is always busy
usually get up
程度（very …）説明する形容詞・副詞の前very fast
頻度副詞の合言葉：「be の後、一般動詞の前」

p.33 Try 2

( )内の副詞を入れよう

(1)He speaks English. (well)彼は英語を上手に話します。
→ He speaks English well.様子の副詞は「動詞＋目的語」の後ろ。✕ speaks well English
(2)She is busy. (always)彼女はいつも忙しい。
→ She is always busy.頻度の副詞 → be動詞の後ろ
(3)Rina walks fast. (very)里奈はとても速く歩きます。
→ Rina walks very fast.very は fast（副詞）を強める → fast の前
(4)I get up at seven. (usually)私はたいてい7時に起きます。
→ I usually get up at seven.頻度の副詞 → 一般動詞の前

Lesson 9　Point

There ＋ be動詞 で「〜がある・いる」

肯定文
単数 → There is a textbook.
複数 → There are some textbooks.
※ be動詞は後ろの名詞の数で決める
否定文・疑問文
否定 → There aren't any textbooks.
疑問 → Are there any textbooks?
答え → Yes, there are. / No, there aren't.
⚠ 否定文・疑問文では some ではなく any！ ⚠ my bag のような特定のものには There is が使えない（My bag is …）

p.34 Get Ready

「〜があります」の文を作ろう

(1)ネコが2匹、机の下にいます。　There …
→ There are two cats under the desk.ネコ2匹＝複数 → There are。「場所」は文の後ろ。
(2)私のかばんは机の下にあります。　My bag …
→ My bag is under the desk.my bag は特定のもの → There is は使えない。ふつうの be動詞 is。

p.34 Practice A

適切な語を選ぼう

(1)There ( am / is / are ) a dictionary under the desk.
→ isa dictionary ＝単数 → is。「机の下に辞書が1冊あります。」
(2)( Am / Is / Are ) there any pictures on the wall?
→ Arepictures ＝複数 → Are。「壁に絵が何枚かありますか。」
(3)There ( am / is / are ) 40 students in our class.
→ are40 students ＝複数 → are。「クラスに生徒が40人います。」
(4)( Am / Is / Are ) there a microwave oven in your house?
→ Isa microwave oven ＝単数 → Is。「家に電子レンジはありますか。」
(5)There ( am / is / are ) some cars in front of the station.
→ aresome cars ＝複数 → are。「駅前に車が何台かあります。」

p.35 Practice B

対話を完成させよう（絵を見て）

(1)Is there any juice in the refrigerator? — No, there isn't. 冷蔵庫の中にジュースはありますか。
juice は数えられない → is / isn't。答えも there を使う。
(2)Are there any flowers in the garden? — Yes, there are. 庭には花がありますか。
flowers ＝複数 → Are there。絵に花が見える → Yes, there are。
(3)Is there an air conditioner in your room? — Yes, there is. あなたの部屋にエアコンはありますか。
an air conditioner ＝単数 → Is there。絵にエアコンが見える → Yes, there is。

Lesson 10　Point

進行形＝ be動詞 ＋ 動詞の -ing形

現在「〜している」
I am using the computer now.
否定 → is not using／疑問 → Is he using …?
過去進行形「〜していた」
be動詞を過去形に！
Nap was sleeping then.
-ing形の作り方例
ふつう → そのまま -inggo→going, play→playing
発音しない e → e をとって -ingmake→making, write→writing
短母音＋子音字 → 子音字を重ねて -ingrun→running, sit→sitting
ie → ie を y に変えて -inglie→lying, die→dying

p.37 Practice A

適切な語を選ぼう（波線の時に注目）

(1)They ( is / are )( play / playing ) catch now.
→ are playingThey ＝複数 → are ／ now → 現在進行形。
(2)I ( was / were )( haveing / having ) dinner then.
→ was havingI の過去は was ／ have は e をとって having。
(3)My parents ( was / were )( watch / watching ) TV when I came home.
→ were watchingparents ＝複数の過去 → were ／ 帰宅した時＝過去進行形。
(4)Emi ( is / was )( writeing / writing ) a letter now.
→ is writingnow → is ／ write は e をとって writing。
(5)It ( is / was )( raining / rainning ) hard at that time.
→ was rainingat that time ＝過去 → was ／ rain はそのまま raining。

p.37 Practice B

対話を完成させよう（(1)(2)は現在・(3)(4)は過去）

(1)Is she reading a comic book now? — Yes, she is.
現在進行形の疑問 Is ＋ 主語 ＋ -ing。絵＝読んでいる → Yes。
(2)Are they playing volleyball now? — No, they aren't.
they ＝複数 → Are。絵はバレーをしていない → No。
(3)Was she watching a movie then? — No, she wasn't.
then ＝過去 → Was。絵はニュース → 映画ではない → No。
(4)Were they drinking wine then? — Yes, they were.
they の過去 → Were。絵はワインを飲んでいる → Yes。

p.37 チャレンジ問題

並べかえよう

語順：主語 ＋ be動詞 ＋ -ing …（疑問は be動詞を前に出す）
(1)私の父は電話中です。
( my father / talking / is ) on the phone.
→ My father is talking on the phone.「電話中」＝話している最中 → 進行形。
(2)あなたはトムを待っているのですか。
( you / are / Tom / waiting for )?
→ Are you waiting for Tom?疑問文なので Are を主語の前へ。
(3)翔太は部屋で宿題をしていましたか。
( doing / Shota / his homework / was ) in his room?
→ Was Shota doing his homework in his room?過去進行形の疑問 → Was ＋ 主語 ＋ -ing。

まとめ

今日のポイント

① There is / are：後ろの名詞が単数なら is、複数なら are。否定・疑問は some → any。
② 特定のもの（my 〜 など）には There is を使わない。
③ 進行形＝ be動詞 ＋ -ing。「今」なら am/is/are、「そのとき」なら was/were。-ing の作り方に注意！
